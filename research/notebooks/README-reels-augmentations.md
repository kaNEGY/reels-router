# Аугментации Reels

`reels_augmentations.ipynb` исследует сохранность визуальных и звуковых сигналов при преобразованиях. Рассматриваются свойства медиа, технические параметры преобразований и сохранность визуальных свидетельств.

## Запуск

Установите зависимости из `requirements-reels-augmentations.txt` в отдельное Python 3.12 окружение с Jupyter. Откройте notebook и выполняйте ячейки по порядку. Для чтения сохранённых outputs сервер не нужен.

`REELS_WORKDIR` задаёт каталог локального кэша. По умолчанию используется `outputs/reels_augmentations` относительно рабочего каталога. Исходные потоки и производные файлы в Git не входят. Для первого получения публичных медиа задайте `REELS_ALLOW_DOWNLOAD=1`; для повторной попытки после сохранённой ошибки дополнительно задайте `REELS_RETRY_FAILED=1`. Учитывайте доступность Instagram и условия использования источника. Cookies автоматически не читаются.

В эксперименте сетевое скачивание выполнено через Windows с разрешения пользователя; декодирование и вычисления выполняются на отдельном CPU-сервере с ограничением двух ядер и 2 ГБ памяти. Абсолютные пути сервера в коде notebook не требуются.

## Интерпретация

- Восемь пользовательских ссылок образуют выборку удобства, а не репрезентативный корпус.
- Два кадра одного ролика не являются независимыми видео.
- При уменьшении разрешения и сжатии нужно проверять читаемость букв, а не только размер или PSNR.
- Изменение темпа аудио меняет длительность: таймкоды следует делить на коэффициент темпа.
- Визуальные наблюдения относятся к указанным примерам и надписям; они не характеризуют все ролики.
- Перед обучением будущие train/test делятся по исходным роликам/авторам; все варианты одного оригинала остаются в одном split.
