## Следующие соединения

Из транскрипта, подписи и отобранных кадров нужно получать упоминания с таймкодами и контекстом сцены. Затем искать кандидатов в геобазе и выбирать объект по свидетельствам, сохраняя ID, координаты и источник. Неоднозначные филиалы требуют уточнения у пользователя. Confidence геокодера ещё нужно сопоставить с ошибками на размеченных примерах.

Объединение подтверждённых точек по регионам, расчёт времени переездов, построение маршрута и Telegram-интерфейс пока запланированы. Поиск кафе в Geoapify демонстрирует ближайшие POI; он сам по себе ещё не формирует план путешествия.

Ключи и личные пути задаются через локальный `.env` по [.env.example](../.env.example). Groq-гайд также принимает ключ через окружение или скрытый ввод. Полные ответы новых поисковых запросов сохраняются в игнорируемый `outputs/`.
